Tentang saya

Saya adalah mahasiswa aktif Program Studi S1 Sistem Informasi di Telkom University Surabaya (Kelas IS-08-02, NIM 108052500014).

Selama menempuh pendidikan, saya memiliki rekam jejak prestasi akademik di antaranya pernah berpartisipasi dan meraih penghargaan dalam Olimpiade Matematika Tingkat Nasional serta kompetisi bahasa Inggris tingkat nasional.

Di luar kelas, saya aktif berorganisasi di lingkungan kampus sebagai anggota Dewan Perwakilan Mahasiswa (DPM), Entrepreneur Community, serta Telkom Art, yang melatih kemampuan kepemimpinan, kerja sama tim, dan eksplorasi kreativitas.

Keahlian

Pengembangan Aplikasi Web

Menguasai pembuatan halaman web dari tingkat dasar hingga lanjutan, mulai dari struktur HTML/CSS, form interaktif, tag semantik, penggunaan framework Bootstrap, hingga kolaborasi kode menggunakan Git dan GitHub.

Perancangan Sistem Informasi

Menguasai perancangan sistem informasi, mulai dari pemodelan proses bisnis BPMN hingga pembuatan diagram UML (Use Case, Activity diagram, dan Class Diagram).

Administrasi Jaringan & Server

Memahami dasar administrasi jaringan dan server lokal berbasis Linux menggunakan Nginx serta BIND.

Pengolahan Data & Konten

Mampu mengoperasikan Microsoft Office (Word dan Excel) untuk penyusunan laporan, dokumen, serta pengolahan data, serta mampu mengedit video untuk kebutuhan pembuatan konten digital yang menarik dan kreatif.
